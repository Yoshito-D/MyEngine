# カメラの回帰テスト

Visual StudioのC++ビルドツールがある環境で、Projectフォルダから実行します。

```powershell
./Tests/Camera/RunCameraTests.ps1
```

実際のカメラ・補間処理をコンパイルして実行します。描画、ログ、エンジン時刻、シーン検索はテスト用サービスへ置き換えます。ビルドは一時フォルダで行い、終了時に削除します。

- ブレンド途中の再切り替えが現在の表示位置から始まり、古いブレンドへ戻らないこと。
- ブレンド先の登録解除・破棄後に参照を残さず、無関係なカメラの解除は補間を中断しないこと。
- 保存位置を初回に維持し、以降の高さ補正でも最小距離と角速度上限を守ること。
- 着地予測の地表法線が重力Upと異なる場合も、同じ制約を守って地表の外側へ復帰すること。
- 設定再読み込みで補間履歴をリセットし、JSON設定を往復保存できること。
- 計測の同一フレーム重複除外、停止、再開が正しく働くこと。
- 旧シーンから独立した`ICinemachineComponent`群を構築し、更新順、個別の無効化、逆順JSONの復元、削除・再追加を正しく処理すること。
- 既定値、GameTest・Tutorialのシーン設定、ガイド無効、遷移時間ゼロ、補間速度ゼロ、旧形式キーを使い、30/60/120FPSと可変時間で13,440フレームの有限値と基底軸を検証すること。

高さ制約外の保存位置や急変したUpに対しては、最小距離と角速度上限を優先して徐々に復帰します。最初のフレームは保存された配置をそのまま使用します。

リファクタリング前後の厳密比較には、変更前に出力したトレースを指定できます。同一コンパイラ・設定・シーンデータで比較してください。

```powershell
./Tests/Camera/RunCameraTests.ps1 -TracePath "$env:TEMP/camera-baseline.bin"
# コードの分割後に実行
./Tests/Camera/RunCameraTests.ps1 -ComparePath "$env:TEMP/camera-baseline.bin"
```

今回のクラス分割では、不具合修正を加える前の段階で483,840個の出力値が変更前と完全一致しました。位置制約の不具合修正を含む最終コードでは、その修正に該当するフレームの出力は変わります。

さらに、不具合修正済みの内部ヘルパー構成と、独立した`ICinemachineComponent`を`VirtualCamera`経由で動かす構成を同じ入力列で比較し、483,840個の出力値の完全一致を確認しています。

実画面の見え方、タイトル決定演出、CameraGravityBridgeとシーンの接続、CSVのファイル出力は、このヘッドレステストの対象外です。
